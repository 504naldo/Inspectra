## Key Design Elements
1. **Consistent Branding**: Logo on every page (top-left)
2. **Professional Typography**: Clean sans-serif font, good hierarchy
3. **Color Scheme**: Navy blue (#003366 or similar), white, black, grayscale
4. **Footer**: Consistent across all pages with address and page numbers
5. **Tables**: Clean borders, good padding, right-aligned currency
6. **White Space**: Adequate margins and spacing for readability

## Implementation Requirements
1. Cover page with hero image background
2. Letter-style summary page with recipient block and signature
3. Deficiency table with Item #, Description, Device, and Total columns
4. Include locations in descriptions
5. Right-aligned currency formatting
6. Consistent footer with page numbers
7. Professional typography and spacing
8. Automatic download instead of opening in new tab
